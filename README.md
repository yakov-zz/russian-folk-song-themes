# What Russians Sang

Themes of 11,000+ Russian folk songs, read by three AI models. Site: https://yakov-zz.github.io/russian-folk-song-themes/ (English,
Portuguese, Russian).

This repository is the built site, served by GitHub Pages. The dataset (one row per song, with text, theme labels,
place, date and source edition) is in [`data/`](data/), with its own README.
