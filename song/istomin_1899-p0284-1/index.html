Съ чужедальной стороны. Не дождамъ дружка милова } 2. Вышла въ поле, поле погулять. Што не пыль-то въ полѣ запылила, } 2. Што не сильный громъ гремитъ, Двое храбрыхъ гранадера } 2. Да я рада бы васъ вотъ пустила Мнѣ васъ нечѣмъ накормить. } 2. Ты хозяюшка вотъ родная, Намъ ненадо-надо ничево. } 2. Скоро въ хату заходили, Садилися они на скамью. } 2. Они другъ на дружка смотрятъ, По чухонски они говорятъ. } 2. Ты хозяюшка вотъ родная, Отчево же ты очень грустна? } 2. Вы служивые, родные, Какъ мнѣ быть-то не грустнóй: } 2. У меня да мужъ въ солдатахъ, Нынче сына отдала; } 2. Лѣтъ семнадцать ли не больше Нѣту слуху, ни письма!
