Sobolevsky, vol. 3 (1897), sobolevsky_3:p0399:24

По мосту-мосточку по калиновому

Courtship and mutual love · primary

По мосту-мосточку по калиновому, По калиновому мосточку, по малиновому, Тутъ и шелъ-прошелъ дѣтина, голубой на емъ кафтанъ, Изъ семи шелковъ кушакъ, да опоясался не такъ: Золотымъ кистьемъ назадъ; полы машутся, Разкамзетовый кушакъ раздувается на емъ. Шиты-браныя манжеты накрахмалены стоятъ; Кругъ шеички платокъ — словно аленькій цвѣтокъ, Въ карманчикѣ второй — вотольянскій голубой; Въ правой рукѣ тросточка камышевая, Вокругъ тросточки ленточка пакетовая. Молодецъ тростьемъ подпирается, Пакетовой лентой похваляется: «Эта лента, эта лента, эта ленточка ала, Да мнѣ сударушка дала. Не ты ль меня, сударушка, повысушила, Повысушила, повыкрушила, Спустила сухоту по моему животу, Разсѣяла печаль по моимъ яснымъ очамъ, Заставила, сударыня, гулять по ночамъ, Что ночамъ, ночамъ, ночамъ, да по позднимъ вечерамъ, Приневолила, сударыня, гостинички носить, Гостинички — сладки прянички?»

Text as printed in the edition, digitised by OCR. Pre-reform spelling may contain recognition errors, and in places the spelling was normalised.
